# Retrieval-Practice-in-KS4-Computing
Research project investigating the impact of retrieval practice on knowledge retention and learning outcomes in KS4 Computing.

## Overview
This research project critically analyses the application of retrieval practice as a cognitive science strategy within KS4 Computing lessons.

## Research Questions
- How effective is retrieval practice in improving knowledge retention?
- How can retrieval activities be integrated into Computing lessons?
- What challenges do teachers face when implementing retrieval practice?
## Key Findings
- Improved long-term retention
- Better student recall during assessments
- Increased engagement when retrieval activities are varied
